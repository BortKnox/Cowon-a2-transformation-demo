# Demo media and provenance

All media in this directory is original work made specifically for the Cowon A2 Field OS demonstration. There are no third-party samples, recordings, stock images, or externally sourced music.

## Audio cues

`audio/track-01.wav` — Signal Path  
`audio/track-02.wav` — Tangerine Circuit  
`audio/track-03.wav` — Night Drive

The three loopable mono WAV cues were procedurally synthesized with the Python standard library by `tools/generate_demo_audio.py`. They are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Regenerate with `python3 tools/generate_demo_audio.py`.

## Visuals

`field-os-still.svg` and `field-os-demo.webm` are original vector illustrations and animation created for this demo. They are also dedicated to the public domain under CC0 1.0. The WebM is a silent six-second loop; the standalone audio tracks can be played from the demo player.
